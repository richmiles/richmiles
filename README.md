# Rich Miles

Software engineer in Laramie, Wyoming. Senior Software Engineer at [Sturdy](https://sturdy.ai), working on AI platforms and LLM pipelines. On my own time I build tools for working with coding agents and run a small fleet of production apps.

## Projects

- **[Sluice](https://github.com/miles-automation/sluice)**: an MCP proxy that loads tool results into DuckDB, so agents query a table instead of reading the raw payload. On PyPI as `mcp-sluice`.
- **[Slopticus](https://slopticus.com)**: a Mac and iPhone workspace for running Claude Code and Codex sessions. The relay is open source: [slopticus-relay](https://github.com/miles-automation/slopticus-relay).
- **[platform-infra](https://github.com/miles-automation/platform-infra)**: the infrastructure behind my apps, including platform-ci, an on-demand CI/CD system that replaced GitHub Actions.
- **[richmiles.xyz](https://richmiles.xyz)**: my site.
